# Short-Form Video Production Specification

Use this specification after the audience, topic, platform, and CTA outcome are known.

## Platform rules

### Instagram Reels

- Target 45–58 seconds and 110–135 spoken words.
- Use a polished, clean aesthetic and clear audio.
- Keep typography and essential framing within the central 1080 × 1440 px safe zone.
- Default CTA when none is selected: Keyword.
- For a Keyword CTA, end with a relevant “Comment [KEYWORD]” incentive. Do not imply that an automated DM exists unless the user confirms it.

### TikTok

- Target 61–65 seconds and 145–160 spoken words.
- Use raw, conversational, lightly unfiltered pacing.
- Use rhetorical questions or tension where natural; do not manufacture controversy.
- Keep text in the upper-middle quadrant. Leave the entire right 150 px and bottom 30% clear of text and essential facial framing.
- Default CTA when none is selected: Community.
- Adapt the CTA toward conversation, saving, following, a bio link, or a video-reply prompt as selected. Do not promise program eligibility or payouts.

### Both

Create two separate scripts. Do not merely change the platform name.

- Instagram must be shorter and more polished, with central safe-zone cues.
- TikTok must be longer and more conversational, with upper-middle text and right/bottom clearance.
- Hooks, pacing, transitions, captions, and CTA wording should fit each platform.
- Preserve the same core idea and audience promise so the versions remain strategically comparable.

## Narrative bridge

Use this sequence while adjusting the final segment for platform runtime:

| Time | Function |
| :--- | :--- |
| 0:00–0:03 | Multi-sensory hook: pattern-interrupt visual plus an absolute spoken hook. Open a specific loop. |
| 0:03–0:12 | Agitate the central flaw, stakes, misconception, or context. |
| 0:12–0:15 | Pivot with a genuine twist, reframe, contradiction, or angle shift. |
| 0:15–0:45 | Deliver three sequential and actionable steps, distinctions, or data elements. |
| 0:45–0:53 | Provide the climax, proof, or core realization and close the opening loop. |
| 0:53+ | Deliver one platform-appropriate CTA tied to the selected outcome. Extend TikTok value and CTA naturally to 61–65 seconds. |

Plan a visible retention beat every three to four seconds. When a table row covers a longer interval, list its internal scale cuts, b-roll changes, gestures, props, or text pop-ups in sequence. Do not require frantic editing when a deliberate pause would improve comprehension.

## CTA adaptation

Use exactly one primary CTA.

| CTA choice | Desired action |
| :--- | :--- |
| Keyword | Comment a short word for a clearly named benefit. |
| Follow | Follow for a specific recurring result or subject, not a generic “more tips.” |
| General | Select the most natural single action for the topic and platform. |
| Community | Answer a focused question, share an experience, or leave a question for a video reply. |
| Link/Bio | Visit a clearly described resource through the link in bio. |
| Save/Bookmark | Save the video for a foreseeable moment when the information will be useful. |
| Custom | Preserve the user's requested action and adapt it to the platform without changing its purpose. |

## Required output

Use these exact primary sections. When Both is selected, include separate platform subsections within each relevant section.

### 1. SHORT-FORM VIDEO CONCEPT & TARGET RUNTIME

- Core Idea / Niche
- Intended Audience
- Platform
- Selected CTA Outcome
- Estimated Duration
- Spoken Word Count
- Retention Open Loop

### 2. PRODUCTION SCRIPT

For each selected platform, use:

| Timestamp | Visual & B-Roll Cue (Platform Safe Zone) | Spoken Audio (VO/Talking Head) | On-Screen Text Overlay |
| :--- | :--- | :--- | :--- |
| 0:00–0:03 | [Pattern interrupt and shot type] | “[Spoken hook]” | “[Bold 3–5 word title]” |
| 0:03–0:12 | [Problem, stakes, and internal retention cuts] | “[Problem context]” | “[Supporting keyword]” |
| 0:12–0:15 | [Pivot and angle or scale switch] | “[Turning-point statement]” | “[Pivot text or graphic]” |
| 0:15–0:30 | [Steps 1 and 2 with retention beats] | “[Value delivery part 1]” | “[Key takeaways 1]” |
| 0:30–0:45 | [Step 3 and evidence, example, or demonstration] | “[Value delivery part 2]” | “[Key takeaways 2]” |
| 0:45–0:53 | [Payoff and loop closure] | “[Final core insight]” | “[Climax text]” |
| 0:53–end | [Ending action and platform framing] | “[Selected CTA line]” | “[One CTA instruction]” |

Do not invent a case study merely to fill the 0:30–0:45 row. Use an honest example, demonstration, explanation, or sourced proof instead.

### 3. THREE HOOK VARIATIONS FOR TESTING

- Curiosity Hook
- Story or Demonstration Hook
- Direct Pain-Point Hook

Each hook must create a credible reason to watch for the payoff. Avoid false absolutes and bait that the script does not satisfy.

### 4. CAPTION & CTA SETUP

- Hook line for caption
- Short caption body with readable line breaks and natural search terms
- Exact CTA wording
- Keyword and promised incentive, when Keyword is selected
- Three to five relevant SEO keywords or hashtags

For Both, provide distinct Instagram and TikTok caption/CTA setups.

## Final production checks

- Count only spoken words when checking the target range.
- Keep on-screen text short and inside the selected platform's safe zone.
- Make every spoken sentence perform hook, tension, value, proof, payoff, or CTA work.
- Remove filler introductions, repeated claims, and unsupported statistics.
- Close the opening loop before asking for the CTA.
